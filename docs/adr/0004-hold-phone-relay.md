# ADR 0004：電話の中継（番号の種類を問わない）を、法務の判断が出るまで保留する

- 状態：採用（法務の判断が出たら見直す）
- 日付：2026-10-17

## 状況

当初の計画には、P1 として050番号での通話の中継があった。調べたところ、次の3つの法律がかかる可能性が高い。

- **電気通信事業法**：他人の通信の媒介に当たり、届出が要る可能性が高い。
- **犯罪収益移転防止法 2条2項44号**：電話転送サービス事業者に当たる可能性が高い。総務省の整理では、要件は番号の利用許諾と自動転送の2つで、番号の種類（03か050か）は判断基準にならない。当たる場合は、契約時の取引時確認（氏名、住居、生年月日、目的、職業）、記録の7年保存、疑わしい取引の届出が義務になる。是正命令の例もある（2024-06）。
- **携帯電話不正利用防止法**：割符が050のアプリ通話を提供すると、050アプリ電話として本人確認の義務を負う可能性がある。

## 決定

- 電話の中継は、番号の種類を問わず、法務（総務省への照会と弁護士の確認。イシュー #14）の判断が出るまで実装しない。
- それまでは、企業から利用者への連絡は、メール中継だけで行う。割符アプリの中に企業からのメッセージを出す機能は、計画にないので作らない。窓口での本人確認は CIBA で行う。
- P0 では、割符は電話番号を集めない。
- 保留の間も、本物の電話番号を本人確認の根拠にしてはならないことは、肯定リスト（ADR 0001）で担保する。
- 原則2（企業に持たせない）は、電話については未達であることを仕様に明記する。

## 再開する場合の条件

- 取引時確認の結果は、別名や中継とは分けた専用の記録庫に置き、企業には一切渡さない。
- 確認の方法は、IC チップか JPKI を使う（2027-04-01 の施行規則改正に合わせる）。
